# Анализ датасета RFSD (на ограниченной выборке)

## Ссылка на репозиторий

GitHub-репозиторий проекта:  
[https://github.com/edwanto/rfsd-analysis](https://github.com/edwanto/rfsd-analysis)

---

## Описание

В этом репозитории представлен учебный анализ датасета **RFSD**.  
Анализ выполнен на случайной выборке **20 колонок и1000 строк** с использованием **Pandas**, **Matplotlib**, **Seaborn** и **datasets**.

Скачанный датасет хранится в формате **Hugging Face Arrow**, данные считываются выборочно, без загрузки всего датасета в память.

---

## Цель работы

Выполнить анализ данных в соответствии с заданием:

1. получить описательную статистику;
2. построить гистограммы для 3 информативных признаков;
3. вычислить и визуализировать матрицу корреляции между всеми колонками;
4. построить диаграммы рассеивания между коррелирующими признаками;
5. сделать выводы по результатам анализа.

---

## Ограничения данных

По условию задания анализ датасета выполняется на сокращенной выборке:

- **20 колонок**
- **1000 строк**

---

## Как была построена выборка

- Найдены все .arrow датасета RFSD.
- Выбраны **10 arrow**, равномерно распределенных по датасету.
- Из каждого arrow случайным образом выбрано одинаковое число строк.
- Итоговая рабочая выборка содержит **1000 строк**.

---

## Какие признаки выбраны

### Мета-признаки

- `region`
- `region_taxcode`
- `age`
- `eligible`
- `filed`
- `imputed`
- `simplified`
- `okved`
- `okved_section`
- `geocoding_quality`

### Финансовые признаки

В датасете финансовые признаки имеют вид `line_XXXX`.  
Для повышения читаемости и улучшения интерпретации таблиц, графиков и выводов они были переименованы с помощью словаря RFSD и нормативных финансовых документов:

- словарь 'aux_data/descriptive_names_dict.csv' из репозитория RFSD на GitHub
- Коды Бухгалтерского баланса (Форма № 1)

- Коды Отчета о финансовых результатах (Форма № 2)

В ноутбуке показана таблица соответствия:
исходное имя -> словарное имя -> имя из нормативного документа.

---

## Что сделано в ноутбуке

### 1. Описательная статистика

- статистика по числовым признакам;
- статистика по категориальным признакам;
- анализ доли пропусков.

### 2. Гистограммы

Построены гистограммы для:

- возраста компании;
- итогового показателя баланса;
- чистой прибыли / убытка.

### 3. Дополнительный анализ

- исследована связь между `filed` и наличием финансовых данных;
- исследован возраст компаний по секциям ОКВЭД.

### 4. Корреляционный анализ

- матрица корреляции по всем 20 признакам;
- отдельная матрица корреляции только для числовых признаков;
- отбор наиболее сильных корреляций.

### 5. Диаграммы рассеивания

Построены scatter plot для:

- итогового актива баланса и итога по пассиву;
- прибыли до налогообложения и чистой прибыли;
- тех же пар в логарифмической шкале.

---

## Основные выводы

1. В выборке преобладают сравнительно молодые компании: медианный возраст равен **5 годам**.
2. Финансовые признаки содержат много пропусков, но пропуски не случайны:
   наличие финансовых данных тесно связано с признаком `filed`.
3. Итог по активу и итог по пассиву баланса имеют сильную положительную корреляцию. Это согласуется с логикой бухгалтерского баланса.
4. Прибыль до налогообложения и чистая прибыль также сильно коррелируют.
      Это соответствует взаимосвязи финансовых показателей.
5. Финансовые распределения имеют сильную асимметрию и содержат выбросы.
6. Корреляции категориальных признаков после числового кодирования интерпретируются условно, основные выводы сделаны по числовым финансовым признакам.
